# Commercialization notes

The hackathon repository is source-available. The hosted SaaS can still be paid because the paid value is not just the code:

- no GCP setup;
- reliable Playwright/ffmpeg execution;
- branded templates;
- 1080p and vertical shorts;
- multilingual narration;
- team workspaces;
- generation history;
- retries and recovery for flaky web apps;
- commercial usage rights.

Possible pricing:

- Free: 1 video/month, watermark, 720p
- Pro: $19/month, 10 videos/month, no watermark
- Team: $99/month, 50 videos/month, brand templates
