# Demo script

1. Open DemoMotion AI dashboard.
2. Enter the demo app URL.
3. Enter the goal: `Show how a founder can create a launch plan from a rough idea.`
4. Click `Generate demo video`.
5. The API plans a scenario, records the workflow, creates narration, renders the MP4, and returns the video.
6. Play the resulting MP4.

Suggested talk track:

> Most builders hate recording demos. DemoMotion AI acts like a product marketer inside a browser. It understands the product goal, performs the workflow, records the screen, writes narration, generates voice-over, and exports a shareable demo video.
